# SMART Med UDH — ระบบออนไลน์ อายุรกรรมอุดรธานี

Launcher page linking all Internal Medicine UDH applications.

## Files
- `index.html` — the page. **To add/change an app, edit the `APPS` list near the bottom.**
- `assets/` — logo and phone icons
- `manifest.webmanifest` — lets staff "Add to Home Screen"

## Updating
Edit `index.html` on GitHub (pencil icon) → Commit changes. Vercel redeploys automatically in ~30 seconds.
